# MRI Viewer

Настольное приложение для просмотра медицинских снимков МРТ и КТ в формате DICOM.

**Что умеет:** просмотр серий · MPR (три плоскости) · 3D-визуализация · измерения · расчёт объёма · сравнение двух исследований · загрузка снимков с PACS-сервера.

---

## 1. Используемые технологии

| Технология | Что это | Как используется в проекте |
|---|---|---|
| **DICOM** | Международный стандарт хранения и передачи медицинских изображений | Чтение файлов через библиотеку **pydicom**: поиск и группировка серий (`scan_folder`), чтение пикселей и тегов (`read_pixels`), сборка 3D-объёма (`load_volume`) |
| **PACS** | Сервер-архив медицинских снимков в больнице | Вкладка «PACS»: поиск исследований (**C-FIND**) и скачивание (**C-MOVE**) |
| **DCMTK** | Набор готовых консольных DICOM-утилит | Внешние программы, которые запускает приложение: `findscu` и `movescu` для PACS, `dcmdjpeg` и `dcmdjpls` для распаковки сжатых снимков |
| **PySide6 (Qt)** | Библиотека графического интерфейса | Окно, вкладки, панели, отрисовка срезов, запуск DCMTK через `QProcess` |
| **NumPy** | Численные расчёты | Хранение объёма, окно яркости, измерения, 3D-рендеринг на процессоре |
| **SciPy** *(необязательно)* | Научные вычисления | Поиск связной области для инструмента «Объём» (`scipy.ndimage.label`) |

**Важно про DCMTK.** Это не Python-библиотека, а отдельные программы. Приложение вызывает их как внешние процессы, поэтому DCMTK нужно установить отдельно и добавить в `PATH`. Без DCMTK просмотр локальных несжатых файлов работает, а PACS и сжатые снимки (JPEG, JPEG-LS) — нет.

**Про PACS.** Сетевой протокол DICOM в коде не реализован. Приложение формирует параметры запроса и передаёт их утилитам DCMTK, а затем разбирает ответ.

## 2. Установка

Требуется Python 3.9+.

```bash
pip install -r requirements.txt
```

Дополнительно:

| Что | Зачем |
|---|---|
| [DCMTK](https://dicom.offis.de/dcmtk) (в `PATH`) | PACS и сжатые снимки |
| `pylibjpeg` или `python-gdcm` | файлы JPEG2000 |

## 3. Запуск

```bash
python mrtViewer.py                  # пустое окно
python mrtViewer.py <папка_DICOM>    # сразу открыть папку
```

## 4. Быстрый старт

1. **Локально → Открыть папку с DICOM…** — серии найдутся автоматически, первая откроется в окне A.
2. Выберите раскладку: **MPR**, **MPR + 3D** или **3D**.
3. Листайте колесом мыши, яркость подбирайте клавишами `1`–`9`.
4. Нужный инструмент измерения выберите на верхней панели.

## 5. Управление

**Мышь**

| Действие | Результат |
|---|---|
| Колесо | листание срезов |
| Ctrl + колесо | масштаб |
| ПКМ / СКМ + перетаскивание | сдвиг |
| ЛКМ | действие инструмента |
| Двойной клик | сброс вида |

**Клавиатура**

| Клавиша | Действие |
|---|---|
| ← ↑ / → ↓ | предыдущий / следующий срез |
| PageUp / PageDown | ±10 срезов |
| `1`–`9` | пресет окна яркости |
| `I` | инверсия |
| Delete / Backspace | удалить последнее измерение |
| Esc | отменить измерение |

## 6. Инструменты

| Инструмент | Как использовать |
|---|---|
| **W/L** | ЛКМ + движение: по X — ширина окна, по Y — центр |
| **Курсор** | клик ставит перекрестие MPR во всех плоскостях |
| **Линейка** | 2 клика → расстояние (мм) |
| **Угол** | 3 клика, вершина — вторая точка |
| **ROI** | эллипс → площадь, среднее ± СКО, min/max |
| **Значение** | клик → значение в точке (HU для КТ) |
| **Объём** | клик по структуре → объём в мл |

Если в файле нет `PixelSpacing`, измерения показываются в пикселях.

**Объём (сегментация).** Вкладка «3D / Анализ» → «Допуск сегментации» (% от ширины окна) → инструмент «Объём» → клик внутри структуры. Если маска «вытекла» — уменьшите допуск, если точка вне допуска — увеличьте. Перед кликом подберите окно, в котором структура хорошо видна.

**Сравнение исследований.** «Добавить папку (для сравнения)…» → включить «Сравнение» → выбрать серию → «→ Окно B» → включить «Синхронизацию». Для разных исследований надёжнее режим «Пропорционально».

## 7. Работа с PACS

Вкладка **PACS**. Настройки:

| Поле | Назначение | По умолчанию |
|---|---|---|
| Хост / Порт PACS | адрес сервера | 127.0.0.1 / 104 |
| AE PACS (called) | имя приложения сервера | ORTHANC |
| Наш AE (calling) | имя нашей программы | MRIVIEWER |
| Наш порт приёма | порт, куда сервер присылает снимки | 11112 |
| Имя, ID, модальность | фильтры поиска | `*`, пусто, MR |

**Порядок работы:** «Найти (C-FIND)» → выбрать исследование в таблице → «Загрузить (C-MOVE)».

**Что происходит внутри:**

| Шаг | Утилита DCMTK | Результат |
|---|---|---|
| Поиск | `findscu` | список исследований в таблице |
| Загрузка | `movescu` | файлы в `~/dicom_cache/<StudyInstanceUID>`, затем папка открывается автоматически |

Вывод утилит виден в журнале под таблицей. Одновременно выполняется только одна операция.

На стороне PACS должны быть зарегистрированы наш AE Title, адрес и порт приёма — иначе поиск сработает, а загрузка завершится ошибкой.

> Кэш `~/dicom_cache` содержит персональные данные пациентов и не очищается автоматически. Соединение DICOM не шифруется — используйте VPN.

## 8. Устройство кода

Весь код находится в одном файле `mrtViewer.py`.

| Блок | Содержимое | Назначение |
|---|---|---|
| Чтение DICOM | `Series`, `scan_folder`, `read_pixels`, `load_volume`, `decode_with_dcmtk` | поиск файлов, группировка в серии, сборка объёма |
| Данные | `Volume`, `make_presets` | 3D-массив `(Z, Y, X)` + геометрия и пресеты окна |
| Измерения | `Measure`, `measure_text` | расчёт расстояний, углов, ROI |
| 2D-вид | `SliceView` | отрисовка среза, мышь, клавиатура |
| 3D-вид | `Volume3D` | программный рейкастинг на NumPy (без видеокарты) |
| Панель | `Panel` | состояние одного окна (A или B): объём, позиция, яркость, измерения, сегментация |
| Главное окно | `MainWindow` | панель инструментов, вкладки, синхронизация, PACS |

**Иерархия:** `MainWindow` → две `Panel` (A и B) → у каждой три `SliceView` и один `Volume3D`.

**Как загружается серия:**

1. `scan_folder` рекурсивно обходит папку, читает только теги (без пикселей) и группирует файлы по `SeriesInstanceUID`.
2. Срезы сортируются по положению вдоль нормали (`ImagePositionPatient` и `ImageOrientationPatient`), иначе по `InstanceNumber`.
3. `read_pixels` читает пиксели через pydicom. Если формат не поддерживается, запускаются `dcmdjpeg` / `dcmdjpls` из DCMTK.
4. Значения переводятся в реальные единицы: `пиксель × RescaleSlope + RescaleIntercept` (для КТ это HU).
5. `load_volume` складывает срезы в один массив `float32`; срезы другого размера пропускаются с предупреждением.

## 9. Частые проблемы

| Проблема | Решение |
|---|---|
| «Не удалось декодировать пиксели» | установить DCMTK или `pylibjpeg` / `python-gdcm` |
| «Не найден findscu/movescu» | установить DCMTK и добавить в `PATH` |
| Не работает «Объём» | `pip install scipy` |
| Измерения в px | в файле нет `PixelSpacing` |
| 3D работает медленно | взять серию поменьше или режим MIP |

## 10. Ограничения

- Серия целиком хранится в памяти (`float32`, 4 байта на воксель).
- Косые срезы не пересэмплируются.
- Измерения и маска сегментации не сохраняются в файл.
- 3D не использует окно яркости и сегментацию.
- Нет поддержки DICOM-SR/SEG и динамических серий.

## 11. Расширение

- **Новый пресет КТ:** добавить пару в `CT_PRESETS`.
- **Новая раскладка:** добавить название в `LAYOUTS` и ветку в `Panel.set_layout`.
- **Новый инструмент:** `MainWindow._build_toolbar`, `measure_text`, `SliceView.mousePressEvent`, `SliceView._draw_measure`.
- **Разрешение 3D:** параметры `fast` / `hq` в конструкторе `Volume3D` (по умолчанию 72 и 144).
