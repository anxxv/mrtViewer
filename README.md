# MRT Viewer

Лёгкий настольный просмотрщик DICOM-исследований (MRI/CT и др.) на Python и PySide6. Умеет открывать локальные папки с DICOM и загружать исследования из PACS через DCMTK (C-FIND / C-MOVE).

## Возможности

- Рекурсивное сканирование папки и группировка файлов по серии (`SeriesInstanceUID`)
- Сортировка срезов по положению в пространстве (`ImagePositionPatient` + `ImageOrientationPatient`), с фолбэком на `InstanceNumber`
- Поддержка многокадровых DICOM (`NumberOfFrames`)
- Ленивая загрузка срезов с LRU-кэшем (по умолчанию 200 срезов)
- Применение `RescaleSlope` / `RescaleIntercept`, окно/уровень (W/L) из тегов или автоматически по 1–99 перцентилям
- Поддержка `MONOCHROME1` (инверсия) и RGB (приводится к яркости)
- Фолбэк-декодирование сжатых данных (JPEG / JPEG-LS) через `dcmdjpeg` / `dcmdjpls` из DCMTK
- Поиск исследований в PACS (C-FIND) и загрузка (C-MOVE) прямо из интерфейса

## Установка

Требуется Python 3.9+.

```bash
pip install numpy pydicom PySide6
```

### Опционально

| Что | Зачем |
|---|---|
| [DCMTK](https://dicom.offis.de/dcmtk) (`findscu`, `movescu`, `dcmdjpeg`, `dcmdjpls` в `PATH`) | Работа с PACS и декодирование JPEG / JPEG-LS |
| `pylibjpeg` или `python-gdcm` | Декодирование JPEG2000 и других сжатых форматов |

Установка DCMTK:

```bash
# macOS
brew install dcmtk

# Debian / Ubuntu
sudo apt install dcmtk

# Windows: скачайте сборку с сайта DCMTK и добавьте папку bin в PATH
```

## Запуск

```bash
python mri_viewer.py
```

Или сразу открыть папку с DICOM:

```bash
python mri_viewer.py /путь/к/папке
```

## Использование

### Локальные файлы

1. Вкладка **«Локально»** → **«Открыть папку с DICOM…»**
2. Выберите серию в списке слева
3. Просматривайте срезы в правой части окна

### PACS

1. Вкладка **«PACS»**, заполните параметры:

   | Поле | По умолчанию | Описание |
   |---|---|---|
   | Хост PACS | `127.0.0.1` | Адрес сервера |
   | Порт PACS | `104` | Порт DICOM на сервере |
   | AE PACS (called) | `ORTHANC` | AE Title сервера |
   | Наш AE (calling) | `MRIVIEWER` | AE Title этого приложения |
   | Наш порт приёма | `11112` | Порт, на который PACS отправит файлы при C-MOVE |
   | Имя / ID пациента | `*` / пусто | Фильтры поиска |
   | Модальность | `MR` | Фильтр по `ModalitiesInStudy` |

2. **«Найти (C-FIND)»** — список исследований появится в таблице
3. Выберите строку и нажмите **«Загрузить (C-MOVE)»**
4. Файлы сохраняются в `~/dicom_cache/<StudyInstanceUID>/` и автоматически открываются

**Важно:** для C-MOVE PACS должен знать ваш AE Title (`MRIVIEWER`) с адресом и портом приёма (`11112`) и разрешать отправку на него. Также убедитесь, что порт приёма не блокируется файрволом.

## Управление

| Действие | Результат |
|---|---|
| Колесо мыши | Листание срезов |
| `↑` `←` / `↓` `→` | Предыдущий / следующий срез |
| `PageUp` / `PageDown` | Шаг на 10 срезов |
| `Ctrl` + колесо | Масштаб |
| ЛКМ + движение | Окно/уровень: по горизонтали — ширина (W), по вертикали — центр (L) |
| ПКМ + движение | Панорамирование |
| Двойной клик | Сброс окна/уровня, масштаба и положения |

## Структура кода

| Элемент | Назначение |
|---|---|
| `Series` | Описание серии и списка срезов |
| `scan_folder()` | Сканирование папки, группировка и сортировка срезов |
| `SliceStore` | Ленивая загрузка пикселей с LRU-кэшем |
| `decode_with_dcmtk()` | Фолбэк-декодирование через DCMTK |
| `Viewer` | Виджет отображения: окно/уровень, зум, панорама |
| `MainWindow` | Главное окно, вкладки «Локально» и «PACS», запуск DCMTK через `QProcess` |

## Ограничения

- Нет измерений, MPR, 3D-рендеринга и аннотаций
- RGB-изображения отображаются в градациях серого
- Не поддерживается DICOMDIR (папка сканируется рекурсивно)
- Для сжатых форматов вне JPEG / JPEG-LS нужны дополнительные библиотеки
- Загруженные из PACS файлы остаются в `~/dicom_cache` — очищайте вручную; они могут содержать персональные данные пациентов
